# 基于 PySide6 的终末地武器基质 app（自用，能跑就行.jpg）  

**目前实现了两种功能**
1. 最高效率规划武器基质**词条与副本选择**方案，优先级按**目标武器基质数量**与**顺带可刷取的武器基质数量**进行排序：
   1. 补图鉴：需要开启 \[检查仓储\]，对已拥有但无对应基质的所有武器进行规划。
   2. 随便刷：需要开启 \[检查仓储\]，对无对应基质的所有武器进行规划。
   3. 手动输入希望刷取的武器。
2. 检查某基质是否有适用武器：根据武器基质词条判断当前版本是否有可使用的武器。

ps: 关于 \[检查仓储\] 功能，需要手动更改 inventory.json 中的值，weapon_possessed 为是否拥有对应武器，weapon_core_possessed 为是否拥有适配的武器基质；对于值，已拥有为 true，未拥有为 false。仓检功能需通过名为**检查仓储**的 checkbox 勾选。
